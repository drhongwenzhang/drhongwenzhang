### Hongwen Zhang, Ph.D.

CTO and co-founder of [Wedge Networks](https://www.wedgenetworks.com), Calgary, Canada.

For more than two decades I have built real-time threat prevention: security that inspects and decides fast enough to stop an attack while it is happening. At Wedge that work became the WedgeSecure Platform, a security decisioning and enforcement stack delivered as WedgeSecure Cloud, Edge, Guard and Wi-Fi.

Our newest addition is WedgeSecure Agent, a sovereign security layer for agentic AI. It decides whether an agent's inputs, tool calls and outputs are safe, and runs on the customer's own edge hardware.

Inventor on Wedge's US patents in network content inspection (US 7,630,379) and line-rate detection of unknown malware (US 11,349,852). Chaired the Metro Ethernet Forum's Security-as-a-Service working group, and co-founded 24C Group, a digital receipt infrastructure company.
